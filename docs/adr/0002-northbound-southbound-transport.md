# 南向北向采用非对称通信模型

边缘网关的南向（云上 MES → 边缘）通过 MQ 订阅消费，因为云上无法主动访问边缘；北向（边缘 → 云上 MES）由边缘主动出站调用 MES 的 HTTP 接口。

> - 状态：已接受
> - Amended by：DS-9 方向显式化（2026-08-21，commit 67ee48c）——方向只是业务标签，不做方向↔入口校验；“南向=MQ、北向=HTTP”是典型形态而非强制绑定，入口由链首动作种类决定。

## Considered Options

- 双向 HTTP：云上无法主动连边缘，被网络拓扑排除。
- 双向 MQ：北向上传也可走 MQ，但 MES 侧已有 HTTP 入站接口时，出站 HTTP 更直接。
- 南向 MQ + 北向出站 HTTP：符合"云上够不到边缘"的现实，是最终选择。

## Consequences

- 边缘需要同时具备 MQ 消费者连接器和出站 HTTP 连接器。
- 北向依赖 MES 提供可被边缘主动调用的 HTTP 入站接口。
